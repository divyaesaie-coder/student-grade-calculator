# Student Grade Calculator

This is a Python-based Student Grade Calculator that calculates total marks, average percentage, and grade based on subject marks entered by the user.

## Technologies Used
- Python

## Features
- Enter multiple subjects
- Input subject marks
- Calculate total marks
- Calculate average percentage
- Generate student grade

## Concepts Used
- Lists
- Loops
- Conditional Statements
- User Input
- Mathematical Calculations

## Project Type
Python Console Application
